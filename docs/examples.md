# 示例场景拆解

底座内置 5 个场景包，覆盖了“同样的阶段换内容”和“裁剪阶段”两种做法。每个场景都可以直接用，也可以作为你自己场景的模板。文件都在 `backend/scenarios/<场景 id>/`。

| 场景 | id | 阶段数 | 类型 | 覆盖的提示词 | 适合拿来改成 |
| --- | --- | --- | --- | --- | --- |
| AI 短片 | `short_film` | 6 | 视频 | 无（使用默认提示词） | 微电影、剧情短片、品牌故事片 |
| 电商广告片 | `ecommerce_ad` | 6 | 视频 | 6 个 | 带货视频、产品宣传片、本地生活探店 |
| 漫剧 | `comic_drama` | 6 | 视频 | 4 个 + 1 个风格 | 动态漫、儿童动画、IP 连载 |
| 旅游宣传片 | `travel_promo` | 6 | 视频 | 5 个 | 城市宣传、景区/酒店/房产宣传 |
| 商品海报 | `product_poster` | 4 | 图像 | 10 个 | 电商主图、社媒种草图、活动海报 |

---

## AI 短片 `short_film`

**定位**：从一句灵感生成多集剧情短片，是底座的默认场景，也是最完整的参考。

- **阶段**：全部 6 个内置阶段。
- **提示词**：全部使用 `backend/prompts/` 的默认版本。默认提示词本身偏向“高冲突、对话驱动的微短剧”。
- **看点**：`scenario.yaml` 只写了名称、默认参数和首页文案，可以看到一个场景最少需要写什么。

## 电商广告片 `ecommerce_ad`

**定位**：输入商品和卖点，生成 30-45 秒竖屏带货视频。

| 设计决策 | 实现方式 |
| --- | --- |
| 广告比剧情短得多 | 剧本阶段 `options` 把每集行数改为 8-14 行；`episodes` 表示“版本数”（用于 A/B 测试） |
| 结构是“钩子—痛点—卖点—证明—行动号召” | `script/generate_script_zh.txt` 重写创作要求，保留剧本格式 |
| 评审看转化效果，而不是戏剧张力 | `script/eval_plot_zh.txt` 改成投放专家视角，并检查广告法极限词 |
| 商品要在每个镜头里长得一样 | `script/meta_extract_zh.txt` 把商品作为第一个“角色”提取；`character/character_zh.txt` 对商品生成四视图（正面/侧面/背面/细节） |
| 设定图质检要适用于商品 | `character/eval_character_zh.txt` 同时支持商品和人物的检查标准 |
| 拍摄场景要适合摆放商品 | `setting/setting_zh.txt` 要求明亮商业布光、画面中心留出空间 |

**产品提示**：在「商品与模特」阶段可以上传真实商品图，替换 AI 生成的形象，后续画面都会参考它。

## 漫剧 `comic_drama`

**定位**：竖屏、多集、一集一个爽点的漫画短剧。

| 设计决策 | 实现方式 |
| --- | --- |
| 多集连载 | 默认 6 集；剧本阶段支持“续写剧集”（内置能力） |
| 每集有钩子和爽点 | `script/generate_script_zh.txt` 加入“一集一个爽点、开场 3 秒冲突、结尾必留钩子” |
| 漫画画风 | 场景自带风格 `comic-drama`（`prompts/style/comic-drama.txt` + `styles` 声明），首页风格列表里会多出「国漫漫剧」 |
| 跨集角色一致 | `character/character_zh.txt` 改为漫画角色设定图，强调发型、瞳孔画法、配色完全一致 |

**看点**：这是 `styles` 字段的示例，演示场景如何自带画面风格。

## 旅游宣传片 `travel_promo`

**定位**：输入目的地和宣传重点，生成 45-60 秒宣传片。

| 设计决策 | 实现方式 |
| --- | --- |
| 以风景和旁白为主，人物是配角 | `script/generate_script_zh.txt` 要求每场对应一个真实景点，旁白占主体 |
| “旁白”不能被当成角色去画 | `script/meta_extract_zh.txt` 明确排除旁白，并把每个景点提取为场景 |
| 场景设定图就是景点风光图 | `setting/setting_zh.txt` 改成风光大片：航拍/广角、突出标志性地貌 |
| 不能编造景点和价格 | 生成和评审提示词都要求景点、美食、风俗真实存在 |

## 商品海报 `product_poster`（纯图像）

**定位**：输入商品卖点，生成一组 3-4 张风格统一的电商海报。

这是**裁剪阶段**的示例：只保留前 4 个阶段，到「海报生成」（`reference_generation`）就结束。`category: image` 的场景不需要视频模型，首页会隐藏视频相关的设置。

| 阶段（内置类型） | 在这个场景里的含义 |
| --- | --- |
| 海报文案（`script_generation`） | 每一“场”是一张海报：构图描述 + 主标题 + 卖点 |
| 商品设定（`character_design`） | 商品四视图 + 海报背景 |
| 版式规划（`storyboard`） | `storyboard/segment_plan_zh.txt` 规定一场 = 一个片段 = 一张海报 |
| 海报生成（`reference_generation`） | `reference/first_frame_zh.txt` 从“视频首帧”改成“海报”，允许并要求画面中出现标题文字；两个质检提示词也改成海报标准 |

**看点**：同一个内置阶段，换一套提示词就能变成完全不同的用途。复用内置阶段比新写 Agent 省事得多，而且自动获得多版本生成、挑选、单张重生成和上传替换等界面能力。

## 怎样选模板

- 你的产品**有剧情和对白** → 从 `short_film` 或 `comic_drama` 开始。
- **要讲清楚一件事物**（商品、服务、知识） → 从 `ecommerce_ad` 开始。
- **以场景和风景为主** → 从 `travel_promo` 开始。
- **只要图片** → 从 `product_poster` 开始。

```bash
python3 scripts/new-scenario.py my_scenario --from ecommerce_ad --name 我的场景
```

接下来按 [30 分钟做出你的第一个场景](tutorial-first-scenario.md) 修改即可。
