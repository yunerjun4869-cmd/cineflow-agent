# 映序 CineFlow · 连贯创作指南

更新日期：2026-11-09。
连贯创作场景把片段并行生成、一致性审查、定向重生成和限流重试串在一起，方便逐段检查和修改。

## 使用

1. 按根目录 README 配置并启动后端与前端。
2. 首页选择“映序 · 连贯创作”，建议先用一集、两个片段的小样例。
3. 在设置页配置文本、图像、视频和视觉模型的密钥。
4. 确认角色/场景设定图和分镜，生成参考图，再运行视频阶段。
5. 在视频阶段查看一致性审查报告：抽样通过、发现问题、待人工检查。
6. 点击“只重生成问题片段”，将审查建议加入这些片段的生成提示词；完成后重新审查。
7. 切换历史视频版本后点击“重新审查”，再人工确认并进入后期。

## 实现范围

| 能力 | 实现 |
| --- | --- |
| 参考库 | 复用角色/场景阶段的用户选中设定图，不另造重复素材库 |
| 并行生成 | 使用线程池与模型注册表并发值；单进程同服务商最多两项连贯创作视频生成任务 |
| 重试 | 每片段默认额外重试一次，可配置 0–3 次，指数退避；不会重跑成功的其他片段 |
| 审查 | 抽取视频首、中、尾帧，与相关设定图、同集上一个片段尾帧一起交给视觉模型 |
| 定向修复 | 审查报告定位到片段 ID，用户触发后将修复建议加入该片段提示词 |
| 版本保护 | 失败不主动替换用户选中的旧版本；报告保存被审查的视频路径 |
| 失败处理 | 抽帧/模型/结构解析失败记为待人工检查，不记为通过 |

连贯创作场景的参数在 `backend/scenarios/continuity_film/scenario.yaml` 的视频阶段 options 中：

- `max_retries`：额外重试次数，默认 1，上限 3。
- `retry_delay_seconds`：退避基数，默认 2 秒，上限 30 秒。
- 服务商并发限额在 `scheduler.py` 的 `PROVIDER_LIMIT` 中，默认 2。

模型注册表并发配置与“启用并发”开关同时有效；此服务商限制只覆盖连贯创作场景。
片段共享已生成的设定图/参考图，因此可以独立生成；未增加依赖前一段生成结果的 DAG 调度。
首尾帧模式使用相邻参考图作为生成条件。

## 验证与边界

- 测试使用替身模型，不发送真实项目素材、不消耗生成额度。
- 系统需安装 ffmpeg 和 ffprobe；缺少工具会显示待人工检查。
- 抽样不能覆盖所有帧、精确口型或完整动作轨迹；模型判断可能误报/漏报，需人工确认。
- 自动重试可能增加费用，供应商超时后也可能已计费；可将 max_retries 设为 0。
- 这不是分布式队列：多进程、多机器部署需增加共享限流与持久任务队列。
- 审查目前检查同一集相邻片段，没有跨集记忆库；不保证每次修复都有效。
- 没有新增真实付费模型效果数据；准确率、可交付率和加速比例均待实测。
